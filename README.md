# Lounasapp Tampere

Lunch picker for central Tampere. Distances are measured from Kehräsaari.

**Live app:** https://erakk.github.io/lounasapp/ (open on your phone → "Add to Home screen"). Every push to `main` redeploys automatically via GitHub Actions.

- Plan: [docs/app-plan.md](docs/app-plan.md)
- Research: [docs/lounaspaikat-tampere-tutkimus.md](docs/lounaspaikat-tampere-tutkimus.md)
- Lunch-list links: [docs/lunch-links.md](docs/lunch-links.md)

## Run the app

```sh
npm install
npm run dev         # http://localhost:5173
npm run build       # rebuilds data, typechecks, builds the installable app into dist/
npm test            # unit tests (Vitest)
npm run e2e         # build + end-to-end tests in a phone-sized Chrome (Playwright)
npm run icons       # re-render PNG app icons from public/icon.svg
```

First time running e2e: `npx playwright install chromium`.

The design mockups are in [docs/mockups/index.html](docs/mockups/index.html).

## Place data

| File | What |
|---|---|
| `data/places.source.ts` | Hand-maintained source. **Edit this file.** |
| `src/data/places.json` | Generated by the build script. Don't edit it by hand. |
| `src/data/categories.ts` | Categories, clusters, origin point |
| `src/domain/schema.ts` | Zod schema shared by the scripts and the app |

```sh
npm install
npm run data        # build places.json, then validate it
npm run typecheck
```

`npm run build:places` fails if a place's `geo` or `link` name doesn't match an entry in `docs/places-geocoded.json` or `docs/lunch-links.json`. `npm run validate` fails on schema errors and only warns about known gaps, such as a missing price.
